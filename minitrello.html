MiniTrello

Full-stack project management app inspired by Trello. Features kanban board with drag-and-drop, workspace & team management, card details (labels, due date, checklist, comments, attachments, activity log), notification system, role-based access control, search, board templates, dark mode, keyboard shortcuts, and responsive design.

Full Tech Stack

Core Framework

Next.js 16 (App Router, Server Components, Server Actions), TypeScript, React 19

Database & Auth

PostgreSQL 16, Prisma ORM, NextAuth.js v5 (JWT), bcryptjs, Google OAuth

UI & Styling

Tailwind CSS v4, shadcn/ui, Lucide React, next-themes, Sonner (toast)

State & Data

Zustand, TanStack Query, Server Components, Server Actions, Zod v4 validation

Drag & Drop

@dnd-kit/core, @dnd-kit/sortable

Architecture

Zero REST API, Optimistic Updates, RBAC (Owner/Admin/Member/Viewer), Activity Log, Position Gap Strategy
